# LOOP : De la Pile au Collisionneur

Jeu idle / tycoon mobile en un seul fichier (`index.html`, HTML/CSS/JS vanilla, Canvas 2D, sons générés en Web Audio). Aucune dépendance, fonctionne hors-ligne.

Fais évoluer une machine de la pile électrique jusqu'au futur collisionneur circulaire (6 stades), avec mini-jeux, publications (prestige), défis, succès, carnet de labo et sauvegarde automatique.

Ouvrir `index.html` dans un navigateur pour jouer.
